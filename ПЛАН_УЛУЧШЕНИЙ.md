## Пункт 1: Убрать inline `onclick` (Must)

### Проблема:
В `index.html` есть 5 кнопок FAQ с `onclick="toggleFaq(this)"`.
Если добавить CSP без `'unsafe-inline'`, FAQ сломается.

### План:
1. Найти все `onclick="toggleFaq(this)"` в блоке FAQ (5 штук)
2. Удалить атрибуты `onclick`
3. Добавить класс `faq-toggle` (уже есть на кнопках)
4. В JS-блоке найти функцию `toggleFaq`
5. Добавить инициализацию слушателей через `addEventListener('click', ...)`:
```javascript
document.querySelectorAll('.faq-toggle').forEach(btn => {
  btn.addEventListener('click', () => toggleFaq(btn));
});
```
6. Проверить что FAQ работает

### Файлы:
- `index.html` — убрать onclick, добавить addEventListener

## Пункт 2: Добавить CSP meta-тег (Should)

### Проблема:
Нет Content Security Policy — XSS-атаки не блокируются на уровне браузера.

### Условие:
Выполнять **только после** Пункта 1 (иначе FAQ сломается).

### План:
Добавить в `<head>` meta-тег:
```html
<meta http-equiv="Content-Security-Policy" content="
  default-src 'self';
  script-src 'self' https://code.iconify.design https://cdn.tailwindcss.com;
  style-src 'self' 'unsafe-inline' https://fonts.googleapis.com;
  font-src 'self' https://fonts.gstatic.com;
  img-src 'self' data: https:;
  connect-src 'self' https://script.google.com;
  frame-ancestors 'none';
  base-uri 'self';
  form-action 'self';
  object-src 'none';
">
```

### Важные детали:
- `script-src` — **БЕЗ** `'unsafe-inline'` (после фикса onclick)
- `style-src` — **С** `'unsafe-inline'` (Tailwind CDN генерирует стили инлайн)
- `connect-src` — `https://script.google.com` (GAS endpoint для квиза и оплаты)
- `frame-ancestors 'none'` — защита от clickjacking

### Проверка:
- Квиз проходит все шаги
- Оплата создаётся (createpayment)
- FAQ открывается/закрывается
- Tailwind стили применяются

## Пункт 3: SRI для Iconify (Should)

### Проблема:
CDN-скрипты подключены без `integrity` хешей.

### Что добавляем:
- **Iconify** — добавить `integrity` + `crossorigin="anonymous"`
- **Tailwind CDN** — **НЕ трогать** (SRI не работает из-за JIT-компиляции)
- **Google Fonts** — **НЕ трогать** (SRI не применим к CSS @import)

### План:
1. Получить хеш:
```bash
curl -s https://code.iconify.design/iconify-icon/1.0.7/iconify-icon.min.js | openssl dgst -sha384 -binary | openssl base64 -A
```
2. Добавить в HTML:
```html
<script src="https://code.iconify.design/iconify-icon/1.0.7/iconify-icon.min.js"
        integrity="sha384-ХЕШ"
        crossorigin="anonymous"></script>
```

## Пункт 4: Rate limit в GAS (Could)

### Проблема:
GAS endpoint доступен без ограничений — можно спамить ботами.

### Нюанс:
GAS не предоставляет IP-адрес клиента напрямую (`e.parameter.userIp` не существует).

### План:
Реализовать упрощённый rate limit через `CacheService`:
- Лимит: не более 30 запросов в минуту
- IP получать через `Session` или заголовки если доступны
- Альтернатива: лимит по `order_id` или по времени

```javascript
function doGet(e) {
  // Rate limit
  var cache = CacheService.getScriptCache();
  var ip = 'unknown'; // GAS не отдаёт IP напрямую
  var key = 'rate_' + ip + '_' + Math.floor(Date.now() / 60000);
  var count = parseInt(cache.get(key) || '0', 10);
  if (count > 30) {
    return jsonOutput_({ ok: false, error: 'Rate limit exceeded' });
  }
  cache.put(key, String(count + 1), 60);
  // ...основная логика...
}
```

### Ограничения:
- Без IP-адреса лимит будет глобальным (на всех пользователей)
- Для более точного лимита нужен прокси (Cloudflare Worker)

## Отклонённые задачи (Skip)

### Cookie banner (GDPR)
**Причина отклонения:** GDPR — regulation ЕС. Сайт klaviron.ru ориентирован на российских пользователей. 152-ФЗ не требует cookie banner в такой форме.

### HMAC для verify
**Причина отклонения:** Текущая архитектура уже защищена (verify проверяет order_id в Sheets + напрямую через ЮKassa API). Rate limit закроет спам. HMAC требует серверный прокси (~$5/мес) — избыточно.

### Tailwind bundled
**Причина отклонения:** Добавляет build-step (npm, postcss, vite). CDN работает для MVP. Вернуться при росте нагрузки.

### Наполнить `nextSteps`
**Причина отклонения:** Не критично. Блок скрывается если пустой. Наполнить после запуска, когда будут отзывы пользователей.

### Капитализация типов
**Причина отклонения:** Стилистическое замечание. Поправить при следующем обновлении текстов.
